# Laboratorio de Métodos Cuantitativos Aplicados a la Gestión

**Estudiante:** Daniel Quezada

Este repositorio está destinado a la entrega de ejercicios prácticos, documentación de procesos y experimentación con modelos cuantitativos utilizando Python.

## Estructura del Repositorio

| Carpeta | Descripción | Temas |
| :--- | :--- | :--- |
| `01_intro_y_datos` | Introducción a Python | Temas 00, 01, 02 (Pandas, Visualización) |
| `02_modelado_y_sistemas` | Modelado | Temas 03, 04 (Funciones, Equilibrio) |
| `03_matrices_y_leontief` | Álgebra Matricial | Temas 05, 06 (Modelo de Leontief) |
| `04_optimizacion_lineal` | Optimización | Temas 07, 08 (Programación Lineal) |
| `05_calculo_y_elasticidad` | Cálculo Aplicado | Temas 09, 10 (Derivadas y Elasticidades) |
| `06_optimizacion_gestion` | Gestión Avanzada | Temas 11, 12 (Optimización aplicada) |
| `07_integrales` | Cálculo Integral | Temas 13, 15 (Indefinidas y Definidas) |
| `08_analisis_inversiones` | Finanzas Cuantitativas | Temas 16, 17 (Análisis de Inversiones) |
| `data/` | Datasets | Archivos de datos locales (no sincronizados) |

---
*Nota: Este proyecto utiliza un entorno virtual (`.venv`) para la gestión de dependencias.*
